# forest_fi asset sources and licenses

Source material for `AgiSIM/extensions/pegasus.simulator/pegasus/simulator/assets/Worlds/isaac_envs/forest_fi.usd`
(built by `AgiSIM/scripts/build_forest_fi.py`). Downloaded 2026-10-16. Everything here is handled as untrusted data: no
script that came with a download is executed, and no `.blend` file is opened. Blender runs only our own scripts, with
`--factory-startup --disable-autoexec`.

## Poly Haven, "Pine Forest" collection (https://polyhaven.com/collections/pine_forest) and textures

- License: **CC0 1.0** (public domain dedication, https://polyhaven.com/license). Attribution is not required.
  As a courtesy we credit "Poly Haven" and the authors listed below.
- Format: glTF 2.0 at 2k texture resolution (`.gltf` + `.bin` + jpg maps). For foliage, the 1k alpha masks are
  also downloaded, because the glTF export ships opaque jpgs. They are used only as data (see the needle check).
- Downloaded by `AgiSIM/scripts/forest_fi/fetch_polyhaven.py`. Every file is md5-verified against the Poly Haven
  API. File lists, URLs and md5 hashes are in `polyhaven_manifest.json`, and the raw API answers are in `api/`.

## friggog/tree-gen (silver birch)

- URL: https://github.com/friggog/tree-gen, cloned at commit `01e872182a0f955349e51bb1a68ed4dfd665f81c`
  (2025-07-11) into `tree-gen_src/tree-gen`.
- Author: Charlie Hewitt (friggog), with contributions by Sami Pflibsen-Jones.
- License: the **code is GPL-3.0**. From the README: "any models generated using the tool are free for use without
  restriction in any context apart from direct sale as assets."
- Use: the two birch prototypes (`birch_a`, `birch_b`) are generated by our script
  `AgiSIM/scripts/forest_fi/blender_treegen.py`. It imports the tree-gen generator (`parametric/gen.py`; the code was
  reviewed first and makes no system, network or file calls) and reads the `silver_birch` preset as a literal (`ast`),
  not as code. Overrides and seeds are in `AgiSIM/scripts/forest_fi/protos.py` (`BIRCH`).
- The GPL code is not copied into AgiSIM or the USD. Only the generated geometry is used, which the author permits.

## Procedural (ours, no third-party content)

- Bilberry (Vaccinium myrtillus) patches: numpy geometry with a fixed seed (`protos.build_bilberry`).
- Birch bark textures (`birch_bark_diff.png`, `birch_bark_base_diff.png`): numpy, seeded (`scene.birch_textures`).
- Terrain heightfield, stand layout and all placements: seeded (`scene.py`).
